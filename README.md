# Alien Tic-Tac-Toe: Cosmic Clash — Website

A responsive, single-page companion website for the **Alien Tic-Tac-Toe: Cosmic Clash** game. It uses a cute cosmic visual theme and includes Home, About, and Contact sections.

## Project links

- **Website source:** https://github.com/build2gitwhy-pixel/Alien-Tic-Tac-Toe-Website
- **Game repository:** https://github.com/build2gitwhy-pixel/MyFirstGame

## Run locally

This is a static HTML site with no build step or dependencies. Open `index.html` in a browser.

## Deploy to Vercel

1. Sign in to Vercel and choose **Add New → Project**.
2. Import `build2gitwhy-pixel/Alien-Tic-Tac-Toe-Website` from GitHub.
3. Keep the framework preset as **Other** (static site).
4. Leave the build command and output directory blank unless Vercel asks for different settings.
5. Deploy.

The page is designed to be responsive, supports keyboard focus indicators, and respects reduced-motion preferences.
